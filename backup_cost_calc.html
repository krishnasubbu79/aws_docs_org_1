The math. Warm storage bills at $/GB-month, prorated by time. Daily cost = stored_GB × rate ÷ days_in_month. A snapshot held part of a month costs that fraction of its GB-month price. Incremental snapshots mean the first backup stores the full used size; each later backup stores only changed blocks (size × daily-change-rate). This tool uses a simple additive model: storage = initial full baseline + retained daily deltas. Real chains can free slightly less when a mid-chain snapshot is deleted (blocks still referenced by newer snapshots are kept), so actual cost is typically at or slightly above this estimate. Restore, PUT/GET request, and cross-region data-transfer-out charges are separate. Rates are US East (N. Virginia) defaults — override for your region. Verify against the AWS Backup pricing page before committing budget.
